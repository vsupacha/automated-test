1. Opamp characterization

LM321 opamp

Single, 30-V, 1-MHz operational amplifier


  • Supply Voltage Range: 3 V to 32 V
  • Gain-Bandwidth Product: 1 MHz
  • Slew rate: 0.4 V/µs
  • Supply Current: 430 µA
  • Input Bias Current: 45 nA
  • SOT-23 package: 2.90 mm x 1.60 mm

Opamp DC characteristics

Behavior of the op-amp with constant (zero or low frequency) input signals

  • Result of mismatches between components inside the op amp
  1. Input Offset Voltage (\(V_{OS}\)):
    input voltage that bring output to 0V (mid of ±V supply)
  2. Input Bias Current (\(I_{B+}\) and \(I_{B-}\)):
    DC currents that flow into inverting/non-inverting inputs
  3. Input Offset Current (\(I_{OS}\)):
    difference between the two input bias currents
  4. Quiescent Current (\(I_Q\)):
    Supply current drawn with no load condition
  1. Open-Loop Voltage Gain (\(A_{OL}\)):
    DC differential voltage gain (very high value) without feedback
  2. Common-Mode Rejection Ratio (CMRR):
    ability to reject signals common to both inputs
  3. Power Supply Rejection Ratio (PSRR):
    ability to reject variations in power supply voltage
  4. Output Voltage Swing (\(V_{OH}\) and \(V_{OL}\)):
    Maximum positive and negative output voltages relative to the rails

Opamp AC characteristics

Behavior of the op-amp with time-varying (alternating) input signals

  1. Gain-Bandwidth Product (GBP):
    product of closed-loop gain and bandwidth in the 20 dB/decade rolloff region
  2. Unity-Gain Bandwidth:
    frequency where open-loop gain drops to 1 (0 dB)
  3. Full-power bandwidth (\(BW_{FP}\)):
    Maximum frequency to deliver a full-amplitude undistorted sine wave
  4. Gain margin (\(G_M\)) - Phase margin (\(\Phi_M\)): key measures of stability in op-amp feedback systems
  1. Slew Rate (SR):
    maximum rate of change (V/µs) of the output voltage
  2. Settling Time (\(t_S\)):
    time required for the output to be within ab error band after step input
  3. Voltage noise density:
    spectral noise voltage per √Hz (nV/√Hz)
  4. Total Harmonic Distortion (THD):
    harmonic distortion introduced by the amplifier.

Opamp characterization

Servo-loop config: using auxiliary (integrator) op-amp to force the DUT’s differential input to zero → negate very high DC open-loop gains

  1. \(V_{OS}\) measurement
  2. \(I_B\) measurement
  3. DC gain measurement
  1. AC gain measurement
  2. DC CMRR measurement
  3. DC PSRR measurement
  1. AC CMRR measurement
  2. AC PSRR measurement


Offset voltage measurement

Offset voltage (VOS): small differential voltage that must be applied between the input terminals to make the output zero.

  • Null feedback with attenuated TP1 (integrated \(V_{OS}\))
  • Voltage TP1 เท่ากับ \(1000 * V_{OS}\)


DC CMRR/PSRR measurement

Ability to reject signals common to both inputs (CMRR) and variations in power supply voltage (PSRR)

  • CMRR: ±2.5V supply voltage → +3.5V/-1.5V
  • PSRR: ±2.5V supply voltage → ±3V

3. TestStand workshop

Running TestStand

Execution

Process model

  • Sequential model (default): test one UUT at a time
  • Batch model: run common steps for each batch, not for each UUT
  • Parallel model: run multiple independent test sequences


TestStand sequence callbacks

MainSequence: Setup → Main → Cleanup


Test results and data logging

Process model → MainSequence (Test Steps) → Step results

Report

  • HTML / XML
  • Automatic generation
  • Review test results
  • Debug & traceability

Logging

  • SQL database
  • Manufacturing records
  • Yield analysis

Data Streams

  • CSV Input/Output
  • Configuration
  • Custom logging


TestStand process tutorial

  1. เมนู Edit > Sequence File Callbacks เพิ่มตัวเลือก ProcessSetup, ProcessCleanup, PreUUT และ PostUUT
  2. กำหนดตัวแปรสำหรับจัดการข้อมูลใน MainSequence
    • FileGlobals: SerialNumber (String), Offset (Number), Limit (Number)
    • Locals: dutValue (Number)
  3. กำหนด step สำหรับการทำงาน
Callbacks Operations
ProcessSetup เพิ่ม Message Popup รับค่า FileGlobals.Offset
PreUUT เพิ่ม Statement
FileGlobals.SerialNumber = Parameters.UUT.SerialNumber
  1. ใช้ breakpoint และ step over เพื่อตรวจสอบการรับค่า

TestStand process tutorial

  1. กำหนดตัวแปร Locals สำหรับการจัดการข้อมูลใน PreUUT
    • Locals.csvRef (Object Reference) และ rowData (Container)
    • เพิ่มสมาชิก SerialNumber (String) และ Limit (Number) ให้ตัวแปร rowData
  2. กำหนด step ใน PreUUT เพื่อนำเข้าค่า Limit
Callbacks Operations
PreUUT เพิ่ม New CSV Input Stream เพื่ออ้างถึงไฟล์ CSV
- ระบุตำแหน่งไฟล์
- กำหนด Input Record Stream Reference เป็น Locals.csvRef
- กำหนด Field Mapping เป็น “0,1”
เพิ่ม Stream Loop สำหรับวนแยกข้อมูล
- กำหนด Input Record Stream เป็น Locals.csvRef
- กำหนด Input Record เป็น Locals.rowData
(Stream Loop) เพิ่ม If-End ตรวจสอบเงื่อนไข
FileGlobals.SerialNumber == Locals.rowData.SerialNumber
(If-End) เพิ่ม Statement อัพเดทค่า Limit
FileGlobals.Limit = Locals.rowData.Limit
เพิ่ม Break เพื่อจบ loop

TestStand process tutorial

  1. กำหนด step ใน MainSequence เพื่อรับและตรวจสอบค่า Limit
Callbacks Operations
MainSequence เพิ่ม Message Popup รับค่า Locals.dutValue
เพิ่ม Statement คำนวณค่า dutValue
Locals.dutValue = Locals.dutValue + FileGlobals.Offset
เพิ่ม Numeric Limit Test ทดสอบว่า dutValue < Limit
- เมนู Config > Adaptors เลือกเป็น None
- กำหนด Data Source เป็น Locals.dutValue
- กำหนดเงื่อนไข LE (<) โดยตั้งค่าเป็น FileGlobals.Limit
  1. ทดสอบป้อนค่าให้ครอบคลุม Pass/Fail

TestStand process tutorial

  1. กำหนดตัวแปร Locals สำหรับการจัดการข้อมูลใน PostUUT

    • เพิ่มสมาชิก idx (Number), SN (String) และ Status (String) ให้ตัวแปร logData

  2. กำหนด step ใน PostUUT เพื่อบันทึกผลในไฟล์ CSV

Test sequence for LM321 opamp

  • เงื่อนไขการทดสอบ \(V_S\) = ±5V
  • Supply current \(I_S\) < 1.2 mA
  • Offset voltage \(V_{OS}\) < 9 mV
  • PSRR > 65 dB
