# ข้อมูลผู้เข้าอบรม

ปรับปรุงเมื่อ 16 พฤศจิกายน 2569 โดยเทียบกับไฟล์ `Bootcamp_EV LabView การรายงานข้อมูลผู้ผ่านการฝึกอบรม.xlsx` ชีต `Bootcampข้อมูลผู้ผ่านการฝึกอบรม` จำนวน 89 คน และทะเบียนรอบเดิมสำหรับระบุรอบอบรม ผู้จัดยืนยันว่าผู้ลงทะเบียนนอกรอบ 7 คนที่สอบถามเพิ่มเติมอยู่รอบ 6

| รอบ | ผู้เข้าอบรมตามรายงาน (คน) |
| --- | ---: |
| 1 | 14 |
| 2 | 11 |
| 3 | 10 |
| 4 | 8 |
| 5 | 17 |
| 6 | 15 |
| 7 | 14 |
| รวม | 89 |

- `อบรมเสร็จแล้ว`: พบชื่อในรายงานผู้ผ่านอบรม
- `ไม่พบในรายงานผู้ผ่านอบรม`: มีชื่อในทะเบียนเดิม แต่ไม่พบในรายงานฉบับนี้ ยังไม่ใช่ข้อสรุปว่าไม่ได้เข้าอบรม
- `ยกเลิก`: เก็บสถานะยกเลิกเดิมไว้เป็นประวัติของรอบนั้น

Dashboard นับแถวที่มีสถานะ `อบรมเสร็จแล้ว` จาก `participants.csv` ของแต่ละรอบโดยตรง และรวมยอดทั้ง 7 รอบเป็น “ผู้ผ่านอบรมจริง” ด้านบน เป้าหมายรวม 140 คนแสดงแยกจากยอดจริง หากโหลดข้อมูลไม่ครบจะไม่แสดงยอดรวมบางส่วนเป็นยอดจริง

`registered` ใน `summary.json` เก็บยอดผู้เข้าอบรมตามรายงานข้างต้นไว้ให้ตรงกับ CSV แต่ dashboard คำนวณทับจาก CSV เมื่อโหลดหน้า เก็บความจุรอบ รูป และข้อมูลประกอบเดิมไว้ คอลัมน์ STEMplus, EWE, ยืนยันวุฒิ, ประเมิน และวัดผลไม่ได้เปลี่ยนสถานะจากการพบชื่อเพียงอย่างเดียว ผู้เพิ่มใหม่จะเว้นช่องเหล่านี้ว่างไว้

รายชื่อที่แสดงยังใช้เฉพาะชื่อเช่นเดียวกับรูปแบบเดิม ไม่คัดลอกเลขประจำตัวประชาชน ข้อมูลติดต่อ หรือข้อมูลส่วนบุคคลอื่นจาก Excel ลงเว็บไซต์
