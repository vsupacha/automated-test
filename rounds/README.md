# ข้อมูลผู้เข้าอบรม

ปรับปรุงเมื่อ 16 พฤศจิกายน 2569 โดยเทียบกับไฟล์ `Bootcamp_EV LabView การรายงานข้อมูลผู้ผ่านการฝึกอบรม.xlsx` ชีต `Bootcampข้อมูลผู้ผ่านการฝึกอบรม` จำนวน 89 คน และทะเบียนรอบเดิมสำหรับระบุรอบอบรม ผู้จัดยืนยันว่าผู้ลงทะเบียนนอกรอบ 7 คนที่สอบถามเพิ่มเติมอยู่รอบ 6

| รอบ | ผู้เข้าอบรมตามรายงาน (คน) |
| --- | ---: |
| 1 | 14 |
| 2 | 11 |
| 3 | 10 |
| 4 | 8 |
| 5 | 17 |
| 6 | 15 |
| 7 | 14 |
| รวม | 89 |

- `อบรม`: ผู้เข้าอบรม 89 คนที่ตรวจสอบกับรายงานและยืนยันรอบแล้ว
- `ยกเลิก`: รายการอื่นทั้งหมด ตามรูปแบบการแสดงผลที่ผู้จัดกำหนด

Dashboard นับแถวที่มีสถานะ `อบรม` จาก `participants.csv` ของแต่ละรอบโดยตรง และรวมยอดทั้ง 7 รอบเป็น “ผู้ผ่านอบรมจริง” ด้านบน เป้าหมายรวม 140 คนแสดงแยกจากยอดจริง หากโหลดข้อมูลไม่ครบจะไม่แสดงยอดรวมบางส่วนเป็นยอดจริง

`registered` ใน `summary.json` เก็บยอดผู้เข้าอบรมตามรายงานข้างต้นไว้ให้ตรงกับ CSV แต่ dashboard คำนวณทับจาก CSV เมื่อโหลดหน้า เก็บความจุรอบ รูป และข้อมูลประกอบเดิมไว้ คอลัมน์ STEMplus, EWE, ยืนยันวุฒิ, ประเมิน และวัดผลแสดง `รอยืนยัน` ทุกรายการ ตามรูปแบบรอบ 1 และคำสั่งผู้จัด โดยไม่ได้ถือว่าการพบชื่อเป็นการยืนยันเอกสารแล้ว

รายชื่อที่แสดงยังใช้เฉพาะชื่อเช่นเดียวกับรูปแบบเดิม ไม่คัดลอกเลขประจำตัวประชาชน ข้อมูลติดต่อ หรือข้อมูลส่วนบุคคลอื่นจาก Excel ลงเว็บไซต์
